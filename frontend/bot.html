AOI 業務系統

🤖 BOT 設定

客服機器人：LINE 官方帳號與網站右下角客服視窗，同一套知識庫與規則；設定都存在你的試算表。
你的 BOT 設定權限是「查看」，只能看不能改。

設定進度

🛡️ 回覆前檢查知識庫根據

打開後，客服機器人產生回覆後會再請 AI 當「檢查員」，核對回覆裡的每個事實（價格、規格、日期、規定、承諾…）是不是都能在這次的參考資料找到根據；沒有根據就不送出，改成請客人找專人（「客服設定」的「找不到答案時」若選直接轉專人，就直接轉專人）。檢查員出錯一律當作不通過，寧可不答也不亂答。
代價：每則回覆會慢一點，也會多花一次 AI 的 token（可以到「🧠 AI 模型」勾選「回覆檢查」另外指定一組比較便宜、比較快的模型）。沒通過的問題會記在「對話與小編接手」的對話紀錄（主題「回覆檢查未通過」），可以看出哪些問題缺資料、該補進知識庫。

運作方式

客人在 LINE 官方帳號或你網站右下角的客服視窗發問 → 機器人從知識庫（常見問答、文件、產品型號與規格、公司簡介）找出相關內容，只根據這些內容回答。
產品底價、供應商資料不會給機器人；機器人不報價。報價、訂購、樣品測試、客訴、客人說「真人」→ 回覆轉真人的文字、首頁備忘錄通知同事，並暫停機器人一段時間讓同事接手；處理完把備忘錄刪除，機器人就恢復。
對話紀錄在「💬 對話與小編接手」可以查；AI 在「🧠 AI 模型」設定（可多個，依序備援）。

💬 回答方式

🚫 這些問題不讓機器人回答，交給專人

客人問到勾選的問題時，機器人不會回答，直接回覆下面的文字、通知同事並暫停。訊息裡有關鍵字就轉；沒有關鍵字但意思一樣的，AI 也會判斷後轉。每一類可以設定「轉給專人時請客人先留下的資料」，接在回覆後面（或前面）。

🙋 轉真人按鈕、留聯繫資料、附圖與選型計算

網站視窗會跳出表單（姓名、公司、電話、Email；至少要有電話或 Email）；LINE 沒辦法跳表單，會在回覆後面請客人直接回覆，客人說了機器人就會記下來。每位客人只問一次，留下的資料在「🧾 聯繫名單」，同時用首頁備忘錄通知有 BOT 權限的同仁。
選型計算的回覆格式（客服機器人與員工助理共用）
需求達不到時（例如沒有相機夠大、視野拍不滿），機器人會告訴客人怎麼調整（放寬精度、縮小檢測範圍、拆視野…）；客人無法調整就請他轉真人。

📚 知識庫來源

RAG：每次先找出跟問題相關的內容，機器人只根據這些內容回答。
產品很多時會讓知識庫變大、回答變慢；機器人回答產品問題都需要有型號與規格資料時再打開。

🔒 客服機器人看得到什麼（資料隔離）

客服機器人只讀取上面勾選的知識庫來源，沒有任何管道連到客戶資料、案件、聯繫紀錄、報價、帳號或員工助理的記憶；客服用的金鑰也不能呼叫員工助理的功能。按下面的按鈕預覽它現在實際看得到的資料。

📚 知識庫

常見問題：一問一答，最準確。文件：貼上或上傳 txt / md / csv / json / html / PDF，系統會自動切成小段，客人問到相關內容才會用到。後台修改最多 5 分鐘後生效。
每一筆都可以填大分類、主題與備註（備註是寫給 AI 看的提示，例如「客人問打光、照明時使用」），機器人會依搜尋流程先分流再找答案。

🧭 搜尋流程與向量

向量 = 把每一筆知識和客人的問題都轉成一串數字，用語意相似度找答案（需要 Gemini 或 OpenAI 相容的 API Key；Claude 沒有這個功能）。新增 / 修改知識時會自動計算。
找不到達到閥值的段落時，機器人會依「客服設定」的「不確定時」處理（請客人轉真人或直接轉給專人）。向量不能用時會自動退回關鍵字檢索，不會讓客人沒有回覆。
🔎 搜尋測試
輸入一個客人可能問的問題，四種流程各跑一次，看找到哪些段落與分數；可以拉閥值試試（只影響這次測試，要套用請按上面的儲存）。

🛡️ 防濫用與流量上限

網站客服視窗是公開的，任何人都能呼叫。有人用腳本大量灌訊息，會白白消耗 AI 費用，也會占用管理系統（同一份 Apps Script）的額度、拖慢業務同仁。超過上限的訊息直接擋下，不會呼叫 AI，客人會看到下面設定的那句話。欄位填 0 = 不限制。
「同一個 IP」的上限就是為了擋「每則換一個新訪客編號」的灌法。學校、公司、手機行動網路常常很多人共用同一個 IP，數字不要設太小（預設 每分鐘 20 則、每小時 120 則）。「全站」上限是最後一道保險；每天 3,000 則 ≈ 預估最多花掉的 AI 次數，可以依你的 AI 預算換算。
⚠️ 上面的「允許嵌入的網站」如果留空，任何網站都能嵌入，不建議。儲存後最多 5 分鐘套用到機器人。

🧑‍💼 員工私人助理

員工用 LINE（員工專用官方帳號）或網站右下角的「智能助理」聊天查資料、交代事情：「今天要追蹤哪些客戶？」「甲公司的聯絡人電話」「記一筆：今天電話聯繫乙公司，下週三再追蹤」。
・員工加官方帳號好友後，下面「成員」會出現一列（待開通、沒有任何權限），首頁備忘錄也會通知；你確認是同事後才開通並設定權限（跟網站帳號同一套：編輯者 / 查看 / 特定）。
・查詢依這個人的權限過濾；新增 / 修改只有 AI「提出」，本人按確認才寫入；刪除只有網站帳號本來就有刪除權限的人（系統管理員）的助理才能提出，一樣要本人確認；助理做的每一件事都會記在備忘錄「助理紀錄」。

🔒 助理能存取的資料（上限）

這裡是整個員工助理的天花板：實際權限 = 成員（網站帳號）的權限與這裡的上限取較小者。例如客戶資料設「不開放」，所有成員的助理都查不到客戶。刪除：只有網站帳號本來就有刪除權限的人（系統管理員）的助理才能提出刪除，而且一樣要本人確認；自己的行事曆 / 工作 / 備忘錄綁定帳號後就能刪。要完全禁止，到右邊取消勾選各個「🗑️ 刪除」項目。
行事曆是每個帳號各自的，需要把 LINE 綁定到網站帳號。
每位成員每天一則「🤖 助理紀錄」備忘錄，依時間記下查詢、提出的修改、確認後執行的結果、刪除、取消與被權限擋下的嘗試。只有有「BOT 設定」權限的人看得到，只有系統管理員能修改或刪除。

👥 成員

LINE 名稱是員工自己的；狀態改成「已開通」才能使用。角色「特定」可以逐一區塊選查看 / 編輯。「綁定網站帳號」讓助理知道是誰（備忘錄、記錄聯繫的人名、個人記憶）；綁定其他人的帳號只有系統管理員可以。

🧠 長期記憶

個人記憶只有那位員工的助理知道；全公司記憶每個人的助理都會帶著（例如公司規定、產品線說明）。員工也可以直接對助理說「記住…」。
📖 員工助理 LINE 設定步驟
  1. LINE Developers 另外建立第二個 Messaging API Channel（員工專用，跟客服的官方帳號分開），複製 Channel secret 與 Channel access token。
  2. Vercel 專案的 Environment Variables 加上 BOT_STAFF_SECRET（員工助理金鑰）、LINE_CHANNEL_SECRET、LINE_CHANNEL_ACCESS_TOKEN，然後 Redeploy。
  3. 員工官方帳號的 Webhook URL 填 https://你的專案.vercel.app/api/line，打開 Use webhook，按 Verify；回應設定一樣關閉「自動回應訊息」。
  4. 把員工官方帳號的 QR code 給同事加好友 → 回到這裡開通並設定權限。
  5. 想要早報：勾「每天推播早報」與成員的「早報」，系統每小時檢查一次，到設定的時間推播（推播會用到官方帳號的每月訊息額度）。

🧠 AI 模型（依順序備援）

可以設定多組（例如一組 Gemini 3.5、一組 3.8），每組勾選要用在哪些功能。用的那組失敗（金鑰錯誤、額度用完、服務忙碌）時，依清單順序自動改用下一組，最後是系統共用的 Gemini；用 ↑ ↓ 調整順序。支援 Gemini、Claude、OpenAI 相容服務（OpenAI、OpenRouter、DeepSeek、Groq…）。
查詢輪數預設 6：複雜的問題（例如先查客戶再查案件再查產品）可以調高，到了上限機器人會用已經查到的資料回答；調高會多花 AI 費用。每個功能只會用一組：勾在另一組會自動移過去；沒勾的功能用「整個系統」那組；都沒有就用系統共用的 GEMINI_API_KEY。向量只能指定給 Gemini 或 OpenAI 相容的組（Claude 沒有 embedding）。API Key 只存在你的試算表設定裡，畫面上只顯示最後 4 碼；金鑰欄留空 = 沿用原本的。

🔌 連線資訊（要貼到 Vercel）

🔒 客服機器人與員工助理用兩把不同的金鑰：客服金鑰只能呼叫客服的功能（知識庫、對話），員工金鑰只能呼叫員工助理的功能。就算客服那邊的金鑰外流，也碰不到員工助理與內部資料。建議各部署一個 Vercel 專案，客服專案只放客服金鑰與客服 LINE，員工專案只放員工金鑰與員工 LINE。
⚠️ 目前還是舊版「共用金鑰」（客服與員工助理共用同一把）。按下面任一個「重新產生」會自動拆成兩把，記得兩邊的 Vercel 都要更新。
重新產生後舊金鑰立即失效，要到對應的 Vercel 專案更新並 Redeploy。

一般設定

🧹 清除對話資料（只有系統管理員）

先看筆數再清除；設定、知識庫不受影響。
📖 LINE 客服設定步驟
  1. LINE Developers 建立一個 Messaging API Channel（客服用官方帳號），複製 Channel secret 與 Channel access token。
  2. Vercel 專案（Root Directory 選 linebot）的 Environment Variables 填 GAS_URL、BOT_CS_SECRET（客服金鑰）、CS_LINE_CHANNEL_SECRET、CS_LINE_CHANNEL_ACCESS_TOKEN，然後 Redeploy。
  3. LINE 官方帳號的 Webhook URL 填 https://你的專案.vercel.app/api/cs，打開 Use webhook，按 Verify。
  4. LINE Official Account Manager → 回應設定：「聊天」保持開啟、打開 Webhook，關閉「自動回應訊息」與「加入好友的歡迎訊息」（改由機器人回覆）。
  5. 回到這頁：填 AI 的 API Key、勾「啟用客服機器人」、建好常見問題，用「🧪 測試聊天」與手機實際測試。
